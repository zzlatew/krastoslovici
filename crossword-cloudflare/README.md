# Кръстословици — Cloudflare Workers + D1

Проектът включва оригиналната игра, регистрация с имейл/парола, HTTP-only сесии, D1 прогрес и запис на проверени завършвания за предварително подготвените кръстословици.

## Публикуване

1. Инсталирайте Node.js 20+ и изпълнете `npm install`.
2. Влезте в Cloudflare с `npx wrangler login`.
3. Създайте база: `npx wrangler d1 create krastoslovici-db`.
4. Копирайте получения `database_id` в `wrangler.toml` вместо `REPLACE_WITH_YOUR_D1_DATABASE_ID`.
5. Създайте таблиците: `npx wrangler d1 execute krastoslovici-db --remote --file=./schema.sql`.
6. Публикувайте: `npm run deploy`.

За локална разработка: `npx wrangler d1 execute krastoslovici-db --local --file=./schema.sql` и `npm run dev`.

## Важни ограничения преди публичен старт

- Това е начална работеща архитектура, **не е одитирана production система**. Добавете rate limiting на вход/регистрация, потвърждение на имейл, забравена парола, защита срещу автоматизирани заявки и политика за личните данни.
- Прогресът се синхронизира с *последният запис печели*; едновременно играене на два таба може да презапише прогрес.
- Завършванията на генерирани на клиента кръстословици не се отчитат в проверената сървърна статистика. При готовите кръстословици проверката на буквите не е защита срещу измама, тъй като отговорите се доставят в HTML. За честна класация са необходими сървърно издадени задачи, сървърно отчитане на време и проверки срещу повторно подаване.
- Локалните броячи „Решени“ и „Рекорд“ в оригиналния интерфейс още са от браузъра; `/api/stats` предоставя отделна сървърна статистика, която може да се изведе в следваща итерация.
- Преди работа с реални потребители настройте архивиране и политика за изтриване на акаунт/данни.
